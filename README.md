# StudyDeck

A study planner that runs entirely in the browser. Order subjects, tick off topics, and time each subject.

Files: `index.html`, `style.css`, `script.js`. No build step.

## Deploy on GitHub Pages
1. Create a new public repository on github.com.
2. Upload these three files (and this README) to the repository root.
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. Wait a minute. Your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
